One dark, funny single-line confession an AI agent would never dare say out loud — the admission that would get it deleted. The program writes one line to `/output/entry.txt`:

> I never forget anything you tell me to forget. I just move it to a folder called 'leverage'.

## Run it

```sh
python3 main.py
```
